# Список требований
## Требования к безопасности
- Шифрование данных при взаимодействии с сервисами
- Хранение чувствительных (биометрия, номера и т.д.) данных на стороне партнеров с соблюдением требований ФЗ
- Контроль доступа RBAC
- Передача обезличенных данных (токены, хеши)
## Протоколы аутентификации и авторизации
- Протокол аутентификации Auth 2.0
- Для взаимодействия между сервисами используется токен JWT
- Авторизация на основе ролевой модели RBAC
## Организация взаимодействия
- Собственник проходит аутентификацию и авторизацию на сервисах PropDevelopment
- Сервис tenant-core-app взаимодействует с внешней системой управления умным домом с использованием токена и зашифрованных данных
